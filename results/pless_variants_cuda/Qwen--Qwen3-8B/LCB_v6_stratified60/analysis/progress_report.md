## LeetCode (30 tasks) — COMPLETE

All 10 configs finished LeetCode. Note: LiveCodeBench's functional-call
test harness (unlike AtCoder's stdin harness) originally overflowed the OS
argument-length limit for some LeetCode problems with many/large private
tests (`OSError`/silent kill in `bench/eval/lcb_executor.py`'s
`_run_lcb_fn_tests`, which passed test data via argv instead of stdin). Fixed
mid-evaluation by switching to a stdin-based payload; all LeetCode files
below were evaluated with the fix in place.
